# 📚 Sistema de Biblioteca

Projeto desenvolvido em C# com o objetivo de simular o gerenciamento de uma biblioteca.

Este projeto faz parte do meu portfólio como estudante de Análise e Desenvolvimento de Sistemas e será desenvolvido de forma incremental, aplicando conceitos de Programação Orientada a Objetos, modelagem de sistemas e metodologias ágeis.

---

## Objetivo

Criar um sistema capaz de gerenciar uma biblioteca, permitindo o cadastro de livros, usuários e empréstimos, evoluindo futuramente para uma aplicação com banco de dados e interface gráfica.
